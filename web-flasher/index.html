After installing Wi-Fi over BLE firmware

Set up Wi-Fi

Choose Wi-Fi over BLE above and install it. Read the 12-character setup code on the board's screen, then connect from this page.

ⓘ The setup code protects the Bluetooth session. Your Wi-Fi password is sent directly to the board and is not saved by this page. Once connected, install the LocalLink speech firmware.
